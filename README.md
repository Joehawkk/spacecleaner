# Space Cleaner

Аркадный вертикальный шутер для Android. Уничтожай космический мусор, выживай как можно дольше и бей рекорды.

### Возможности

- Управление перетаскиванием: корабль следует за пальцем по горизонтали
- Нарастающая сложность: мусор ускоряется и спаунится чаще с каждой секундой
- Три режима стрельбы: одиночный, двойной и тройной залп
- Система комбо до 5х: уничтожай мусор без остановки, чтобы множить очки
- Бонусы: щит, двойной и тройной выстрел
- Анимация влёта корабля и огненный след из двигателя
- Частицы взрывов при уничтожении мусора
- Красная вспышка экрана при получении урона
- Топ-5 рекордов сохраняется между сессиями

### Дополнительно реализовано сверх технического задания

- Двойной и тройной выстрел: два новых типа бонусов (х2 и х3), активируют режим многоствольной стрельбы на 10 секунд
- Анимация влёта корабля: при старте корабль плавно вылетает снизу экрана с плавным замедлением
- Огненный след: непрерывный выхлоп из двигателя корабля в виде частиц
- Пул объектов: пули и частицы переиспользуются через пул вместо создания новых, снижая нагрузку на сборщик мусора
- Разнообразие мусора: 3 размера (маленький, средний, большой) и 4 цветовых варианта (обычный, металлический, ржавый, органика)
- Таймер мультивыстрела в HUD: показывает сколько секунд осталось до конца режима х2 и х3

### Стек

Java, LibGDX 1.12.1, Android Gradle Plugin 8.3.2

### Сборка

```
git clone https://github.com/Joehawkk/spacecleaner.git
cd spacecleaner
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
gradlew assembleDebug
```

APK окажется в `android/build/outputs/apk/debug/`.

### Установка на устройство

```
adb install android/build/outputs/apk/debug/android-debug.apk
```

Требуется Android 5.0 и выше.
